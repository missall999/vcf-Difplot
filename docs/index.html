vcf-DifPlot

R ≥ 3.6 Open Source

An R script for plotting variant positions from VCF files, comparing genotypes between two samples across chromosomes.

Overview

This tool reads a tab-delimited file converted from VCF format (via GATK VariantsToTable) and creates visualizations showing variant positions across chromosomes. It compares genotypes between a baseline sample and a comparison sample, highlighting positions where they differ.

Prerequisites

  • R (version 3.6 or higher)
  • R packages: ggplot2, optparse, data.table
  • GATK (for converting VCF to tab-delimited format)
install.packages(c("ggplot2", "optparse", "data.table"))

Quick Start

Step 1: Convert VCF to Table

gatk VariantsToTable \
   -V input.vcf \
   -F CHROM -F POS -GF GT \
   -O output.table

Step 2: Generate Plot

Rscript vcf_difplot.R -i output.table -b sample1 -c sample2 -o variant_plot.pdf

Usage

Rscript vcf_difplot.R [options]

Required Arguments

FlagDescription
-i, --input FILEInput tab-delimited file (required)

Sample Selection

FlagDescription
-b, --basename NAMEBaseline sample name
-B, --basecol INTBaseline sample column position (1-based)
-c, --copname NAMEComparison sample name
-C, --copcol INTComparison sample column position (1-based)
For each sample, use either the name flag (-b/-c) or the column-index flag (-B/-C). If both are given, the name takes precedence.

Optional Arguments

FlagDefaultDescription
-o, --output FILEvariant_plot.pdfOutput plot file (PDF, PNG, JPEG, SVG)
-l, --chrlength FILEauto-detectChromosome length file (CHROM LENGTH)
-u, --unit NUM1e6Chromosome length unit (1e6=Mb, 1e3=kb)
--baseHetcheckoffOnly include positions where baseline is homozygous
--copHetcheckoffOnly include positions where comparison is homozygous
--segmentColor COLORredColor for variant position segments
--segmentSize NUM0.5Thickness of variant segments
--chrBorderColor COLORblackColor for chromosome borders
--chrBorderSize NUM0.3Thickness of chromosome borders
--output_table FILEnoneWrite variant positions (CHROM, POS) to file
-I, --interactiveoffInteractive mode: prompts for each parameter

Genotype Handling

  • Supports both / and | as separators (phased and unphased)
  • Treats A/T and T|A as equivalent (normalizes for comparison)
  • Automatically filters out positions with missing data (./.) or wildcards (*/*)
  • Supports haploid genotypes (e.g., male chrX/chrY) and polyploid genotypes (3+ alleles)
  • Can optionally filter for homozygous positions only
  • Smart chromosome sorting: natural numerical order (Chr1, Chr2, ..., Chr10, X, Y, MT)

Output

The script generates a plot where:

  • Each chromosome is represented as a horizontal rectangle (light gray)
  • Variant positions (where genotypes differ) are shown as vertical lines (red by default)
  • The x-axis shows position (scaled by the specified unit)
  • The y-axis lists chromosomes

Supported output formats: PDF, PNG, JPEG, SVG. Format is determined by file extension.

Example

Rscript vcf_difplot.R \
  -i variants.table \
  -b sample1 \
  -c sample2 \
  -o comparison.pdf \
  -l chr_lengths.txt \
  -u 1000000 \
  --baseHetcheck \
  --segmentColor red \
  --segmentSize 0.5
